🌐 Base URL

http://127.0.0.1:5000

All API endpoints and media URLs are accessed relative to your Base URL.

📌 Important: Raw Media URLs, Proxy Endpoint & Expiration
  • Raw Source URLs & Proxy Endpoint: API responses return raw source URLs for generated media (result_url) and reference images (reference_image_urls) (e.g. https://storage.example.com/output.jpg). To download or view the file via your server's proxy, pass the raw source URL to the proxy endpoint: http://127.0.0.1:5000/api/proxy?url=https://storage.example.com/output.jpg.
  • ⏳ 1-Hour Download Window: Generated media files are available for download for 1 hour. Please download and save files to your own storage before the link expires.

📈 Check Quota

GET /api/quota

Check your remaining quota available for generation tasks.

10
Maximum Concurrent Tasks Up to 10 tasks can run simultaneously. Check available_slots in the quota response to know how many slots are free before submitting new tasks. 
curl -X GET http://127.0.0.1:5000/api/quota \
  -H "Authorization: Bearer YOUR_API_KEY"
import requests

url = "http://127.0.0.1:5000/api/quota"
headers = {"Authorization": "Bearer YOUR_API_KEY"}

response = requests.get(url, headers=headers)
print(response.json())

Success Response (200 OK)

{
  "quota": 42,
  "running_tasks": 1,
  "max_concurrent": 10,
  "available_slots": 9
}
⚠️ Important Quota Information:

Every successful API operation consumes 1 Quota unit. This applies to:

  • Image Generation (Text-to-Image or Image-to-Image)
  • Video Generation (Text-to-Video or Image-to-Video)

Once the quota reaches 0, new generation requests will fail.

🖼 Image Generation

POST /api/generate/image

Generate images from text prompts or transform existing images.

Request Body

Parameter Type Required Description
prompt string Required Text description of the desired image. Max 2500 characters (up to 8000 for GPT_IMAGE_2).
reference_images array Optional Array of base64 encoded images for reference / image-to-image transformation.
• NANO_BANANA: Up to 3 images
• NANO_BANANA_2, NANO_BANANA_PRO, GPT_IMAGE_2: Up to 5 images
model string Optional Model version (default: NANO_BANANA)
Options: NANO_BANANA, NANO_BANANA_2, NANO_BANANA_PRO, GPT_IMAGE_2
resolution string Optional Image resolution (default: 1K):
• NANO_BANANA: 1K only
• NANO_BANANA_PRO & NANO_BANANA_2: 1K, 2K, 4K
• GPT_IMAGE_2: 1K, 2K
size string Optional Aspect ratio for all image models:
1:1, 16:9, 9:16, 4:3, 3:4
(default: 1:1)
📌 Model Compatibility:
  • NANO_BANANA (default): Resolution 1K only, up to 3 reference images, all aspect ratios (default: 1:1), prompt max 2500 chars.
  • NANO_BANANA_PRO: Resolutions (1K, 2K, 4K), up to 5 reference images, all aspect ratios (default: 1:1), prompt max 2500 chars.
  • NANO_BANANA_2: Resolutions (1K, 2K, 4K), up to 5 reference images, all aspect ratios (default: 1:1), prompt max 2500 chars.
  • GPT_IMAGE_2: Resolutions (1K, 2K), up to 5 reference images, all aspect ratios (default: 1:1), prompt max 8000 chars.

    "resolution": "2K",
    "size": "16:9"
  }'

🎥 Video Generation

POST /api/generate/video

Generate videos from text prompts or animate existing images using VEO_3_1 or GROK_VIDEO models.

Request Body

Parameter Type Required Description
prompt string Required Text description of the desired video/animation. Max 4000 characters.
model string Optional Video generation model:
• VEO_3_1 (default) — Veo 3.1 (4, 6, 8 seconds; 720p, 1080p)
• GROK_VIDEO — Grok Video (8 seconds; 720p)
size string Optional 16:9, 9:16 (default: 16:9)
duration integer Optional Duration in seconds:
• VEO_3_1: 4, 6, 8 (default: 4)
• GROK_VIDEO: 8 (default: 8)
resolution string Optional Video resolution:
• VEO_3_1: 720p, 1080p (default: 1080p)
• GROK_VIDEO: 720p (default: 720p)
start_frame string Optional Base64 encoded start frame image for image-to-video animation. Supported by VEO_3_1 and GROK_VIDEO.
end_frame string Optional Base64 encoded end frame image. Requires start_frame to also be provided. Supported by VEO_3_1 and GROK_VIDEO.
📌 Video Model Info:
  • VEO_3_1 (default): Duration: 4, 6, 8 seconds. Resolution: 720p, 1080p (default: 1080p). Supports Text-to-Video and Image-to-Video (Start Frame, Start + End Frame).
  • GROK_VIDEO: Duration: 8 seconds. Resolution: 720p (default: 720p). Supports Text-to-Video and Image-to-Video (Start Frame, Start + End Frame).
  • Supported Sizes: 16:9, 9:16 (default: 16:9)

📊 Task Status

10
Maximum Concurrent Tasks The system can process up to 10 tasks simultaneously. New tasks beyond this limit will remain in pending state until a slot opens.

Check Single Task Status

GET /api/status/{task_id} 
curl -X GET http://127.0.0.1:5000/api/status/abc123-def456 \
  -H "Authorization: Bearer YOUR_API_KEY"
import requests

url = "http://127.0.0.1:5000/api/status/abc123-def456"
headers = {"Authorization": "Bearer YOUR_API_KEY"}

resp = requests.get(url, headers=headers)
print(resp.json())
📌 Result URL, Proxy Download & Task Logs:
  • Raw Source URLs: result_url and reference_image_urls are returned as direct source URLs (e.g. https://storage.example.com/output.jpg). To access or download them through the proxy, pass the raw source URL to the proxy endpoint: {BASE_URL}/api/proxy?url={RAW_SOURCE_URL} (e.g. http://127.0.0.1:5000/api/proxy?url=https://storage.example.com/output.jpg).
  • ⏳ 1-Hour Download Window: Generated images and videos are available for download for 1 hour from creation. Ensure your application downloads and saves them locally within this period.
  • Task Logs: The logs array contains task execution logs with message and time.

Pagination (Optional)

By default /api/status returns all tasks. Add page and per_page query parameters to paginate results.

Parameter Type Default Description
page integer — Page number (starting from 1). If omitted, all tasks are returned without pagination.
per_page integer 6 Number of tasks per page. Only used when page is provided.

Paginated Response (200 OK)

// GET /api/status?page=1&per_page=6
{
  "tasks": [ /* ... */ ],
  "running_tasks": 1,
  "max_concurrent": 10,
  "page": 1,
  "per_page": 6,
  "total": 42,
  "total_pages": 7
}

Status Values

Status Description
pending Task created, waiting to start
running Task is currently processing
completed Task finished successfully, result_url available
failed Task failed, check logs for details
error Task encountered an error
timeout Task exceeded time limit

Best Practices

  • Poll task status every 10 seconds for image tasks
  • Poll task status every 5–10 seconds for video tasks
  • Image generation takes approximately 30–120 seconds
  • Video generation takes approximately 60–300 seconds
  • Proxy Endpoint: To access or download returned media via proxy, pass the raw source URL to {BASE_URL}/api/proxy?url=....
  • ⏳ 1-Hour Expiration: Download and persist generated media within 1 hour before links expire.
  • Always check quota before submitting multiple tasks
  • Store task IDs for later retrieval
